1.5.7k deutsch ist ein Service Pack für 1.5.7j deutsch
Die integrierten Module und 3rd Party Komponenten werden auf den Stand von April 2026 gebracht.
PHP 8.4.x wird nun vollständig unterstützt.
Der integrierte Plugin Manager kann nun auch neuere Module, die als encapsulated Plugins veröffentlicht werden, verarbeiten.
1.5.7k behebt auch alle Fehler die seit Erscheinen von 1.5.7j auf Github gemeldet wurden.

Aktualisierte Komponenten gegenüber 1.5.7j:
- Braintree Zahlungsart
- CKEditor
- TinyMCE
- PHP Mailer
- Font Awesome
