Zen Cart 1.5.7k deutsch 

Version vom 23.05.2026

#####################################################################################################################################

1.5.7k deutsch ist ein Service Pack für 1.5.7j deutsch
Es integriert die fast vollständige Codebasis der aktuellen amerikanischen Version 1.5.8 und ein Großteil der amerikanischen Version 2.0.0/2.1.0 in die deutsche Zen Cart Version 1.5.7.
Damit wird PHP 8.4.x vollständig unterstützt.
Der integrierte Plugin Manager unterstützt nun auch neuere als encapsulated plugins veröffentliche Module.
Die integrierten Module und 3rd Party Komponenten werden auf den Stand von Mai 2026 gebracht.

Die Umstellung der Sprachdateien, die die amerikanische Version 1.5.8/2.0.0/2.1.0 bereits mitbringt, wird in einer für 2027 geplanten deutschen Zen Cart Version 2.2.0 mit vollständiger PHP 8.5 Unterstützung nachgezogen.
Dadurch kann in 1.5.7k weiterhin mit den gewohnten Sprachdefinitionen gearbeitet werden. 

1.5.7k behebt auch alle Fehler die seit Erscheinen von 1.5.7j auf Github gemeldet wurden.

Aktualisierte Komponenten:
- PHP Mailer Update auf 7.0.2
- CKEditor Update auf 5
- TinyMCE Editor Update auf 8.4.0
- braintree_web Update auf 3.141.0, braintree_php Update auf 6.34.0 
- FontAwesome Update auf 7.2.0

Wer bereits 1.5.7j verwendet kann mit dem speziellen Updatepaket in UPDATE-VON-157j-AUF-157k sehr leicht auf 1.5.7k aktualisieren.
Anleitung dazu in der liesmich.txt im Ordner UPDATE-VON-157j-AUF-157k

Für das Update einer älteren deutschen Zen Cart Version als 1.5.7 (Sie verwenden z.B. derzeit 1.5.6 oder 1.5.5), führen Sie bitte ein normales Update mit dem kompletten 1.5.7j Paket durch!
Detaillierte Updateanleitung für das Update solch älterer Versionen:
* https://updateanleitung.zen-cart-pro.at

#####################################################################################################################################

Hinweise zu Error Logs unter PHP 8:
Aufgrund des Override Systems für Sprachdateien in Zen Cart 1.5.x ist es unvermeidlich, dass es "doppelte" Sprachdefinitionen gibt.
PHP 8 wird doppelte Sprachdefinitionen mit einem Logfile quittieren und darauf hinweisen.
Unter Konfiguration > Protokollierung/Logfiles ist daher beim Logfiles Level für Adminbereich und Frontend "IgnoreDups" voreingestellt. 
Das sollte auch so bleiben, die Einstellung Yes führt zu unzähligen, völlig unnötigen Warning Logs
